# LogixLoops brand assets

Everything here is generated by `scripts/brand/build.py`. Do not hand-edit
these files, edit the pipeline and rebuild, or the next run will silently
overwrite your changes.

```bash
python scripts/brand/fetch_fonts.py          # once: Orbitron + Inter
python scripts/brand/fit_report.py           # once: fit type to the artwork
python scripts/brand/build.py --scale 2 --out public/brand
```

## Two different jobs

The **fox** is vectorised from the source raster: classified into flat colour
classes, cleaned, and traced with potrace.

The **type is not traced.** The lockup is set in Orbitron and Inter, so those
outlines already exist, tracing them would only recover the JPEG's blurred
edge, giving wobbling stems and drifting counters. `fit_report.py` fits each
string's size, position, tracking and condense to the artwork by minimising
error against its anti-aliased coverage, and `build.py` emits the font's own
curves. That is why `logo-wordmark.svg` is 5.8 KB and razor sharp.

| | Face | Weight | Condense | Fit (IoU) |
| --- | --- | --- | --- | --- |
| Wordmark | Orbitron | 900 | 0.832 | 0.82 |
| Tagline | Inter | 600 | 1.080 | 0.82 |

Weights were chosen by measurement, not by eye, the tagline's error curve has
a clear minimum at Inter 600. Recorded in `scripts/brand/typefit.json`.

## Palette

Measured from the artwork: each value is the median of the pixels that class
actually claimed. Mirrored in `tokens.json`.

| Token   | Hex       | Where it appears                          |
| ------- | --------- | ----------------------------------------- |
| `navy`  | `#081D4A` | Fox outline, wordmark                     |
| `blue`  | `#378CE7` | Fox head, tail sweeps, the wordmark tittle |
| `royal` | `#2868C6` | The ear's leaf                            |
| `steel` | `#336BAF` | Tagline type and its rules                |

The source also carries pale blue-grey bands through the body and tail. They
read as drop shadows rather than as part of the mark, so the pipeline folds
them into the white beneath, flat and crisp rather than shaded. `royal` is
kept only where it is genuinely a flat shape: a component ringed by the navy
outline. Elsewhere the same colour is just the dark end of a gradient inside a
blue sweep, and keeping it there shatters the sweep into blotches.

## Vectors

| File                      | Contents                                | viewBox        |
| ------------------------- | --------------------------------------- | -------------- |
| `logo-full.svg`           | Fox + wordmark + tagline (stacked)      | 1312 × 1118    |
| `logo-lockup.svg`         | Fox + wordmark, no tagline              | 1312 × 1029    |
| `logo-horizontal.svg`     | Fox left, wordmark right, used in nav  | 2058 × 483     |
| `logo-fox.svg`            | Mark only, white fur filled             | 948 × 746      |
| `logo-fox-knockout.svg`   | Mark only, fur transparent              | 948 × 746      |
| `logo-wordmark.svg`       | "LogixLoops" only                       | 1312 × 241     |
| `logo-tagline.svg`        | "Your Unfair Advantage" + rules         | 1234 × 67      |
| `icon.svg`                | Fox centred in a square                 | square         |
| `logo-*-navy.svg`         | Single colour, for light backgrounds    |,              |
| `logo-*-white.svg`        | Single colour, for dark backgrounds     |,              |

Each SVG groups its paths by region (`#fox`, `#wordmark`, `#tagline`), so a
group can be pulled out or animated independently.

`logo-fox.svg` paints an opaque white plate under the mark: the fur bands read
as white on purpose, and the plate also means a sub-pixel seam between two
traced layers shows white rather than whatever the logo is sitting on. Use
`logo-fox-knockout.svg` when the background should show through the fur.

## Rasters

`png/` holds transparent exports (fox at 256/512/1024, full lockup at
512/1024/2048, wordmark and horizontal at 1024, plus a white lockup for dark
backgrounds). They are rendered from the same curves the SVGs ship, not from
the source JPEG, so they cannot drift from the vectors.

## Icons

| File                     | Used by                                              |
| ------------------------ | ---------------------------------------------------- |
| `favicon.ico`            | Browser tab (16/32/48/64/128/256 in one file)        |
| `icon-192.png`           | Web app manifest                                     |
| `icon-512.png`           | Web app manifest                                     |
| `icon-512-maskable.png`  | Android adaptive icon, art inside the 80% safe zone |
| `apple-touch-icon.png`   | iOS home screen (opaque plate, iOS ignores alpha)    |

Copies live at `src/app/favicon.ico`, `src/app/icon.png` and
`src/app/apple-icon.png`, which is where Next's file conventions look for
them; `src/app/manifest.js` points at the `/brand/` copies. Re-copy those three
after a rebuild if the mark changes.
